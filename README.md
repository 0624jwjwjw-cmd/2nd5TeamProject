# 대식가 키우기 TV 🍽️📺

> 먹방 BJ 매니저가 되어 재료를 구매하고 요리를 만들어 라이브 방송으로 구독자와 후원금을 올리는 2D 타이쿤 게임

**팀명**: 슈퍼정재운과 아이들
**개발 기간**: 2026.08.05 ~ 2026.09.04
**플랫폼**: Mobile (터치 입력)
**엔진**: Unity 6000.3.7f1 (URP 2D)

---

## 🎮 게임 소개

플레이어는 먹방 BJ의 매니저가 되어 다음 루프를 반복하며 채널을 키워나갑니다.

1. **상점**에서 재료·레시피·업그레이드 구매
2. **주방**에서 재료를 조합해 요리 제작
3. **스튜디오**에서 라이브 방송을 진행해 구독자·후원금 획득
4. 벌어들인 재화로 다시 상점에서 업그레이드

## 🧩 데이터 파이프라인

게임 데이터는 엑셀(`대식가_키우기_TV_데이터.xlsx`)로 관리되며, 다음 시트로 구성됩니다.

- 재료 / 음식 / 특별한 음식 / 등급
- 주방 업그레이드 / 스튜디오 업그레이드 / 레시피 / 셰프 고용

엑셀 데이터는 시트별로 개별 CSV 파일로 나누어 내보냅니다.

| CSV 파일 | 내용 |
|---|---|
| `Ingredient.csv` | 재료 |
| `Dish.csv` | 음식 |
| `SpecialDish.csv` | 특별한 음식 |
| `Grade.csv` | 등급 |
| `KitchenUpgrade.csv` | 주방 업그레이드 |
| `StudioUpgrade.csv` | 스튜디오 업그레이드 |
| `InventoryUpgrade.csv` | 인벤토리 업그레이드 |
| `ReciepePurchase.csv` | 레시피 구매 |

이렇게 종류별로 분리된 CSV 파일들은 `Assets/02_Scripts/Editor`의 커스텀 임포터(`DataImporter.cs`, `CSVParser.cs`)를 통해 `Assets/04_Data`의 `ScriptableObject` 에셋으로 변환되어 게임에서 사용됩니다.

## 🍳 핵심 시스템

### 조리 시스템
- 조리 슬롯은 최대 3개이며, 같은 재료를 클릭하면 슬롯 개수가 증가하고 다른 재료는 새 슬롯에 추가됩니다.
- 슬롯 구성이 어떤 음식 데이터의 재료 조합과 정확히 일치해야 요리가 성공으로 판정됩니다.
- ⚠️ 해당 레시피가 **먼저 해금되어 있어야** 조리 결과가 정상적으로 나옵니다. 미해금 레시피는 재료 조합이 일치해도 요리가 제대로 완성되지 않으니, 조리가 안 될 경우 레시피 해금 여부부터 확인해주세요.

### 레시피 해금
- 각 음식 데이터(`DishData`)는 자체적으로 해금 여부를 가지며, 해금 관리자가 해금 상태를 전담 관리합니다.
- 상점에서 레시피북을 구매하면 해당 레시피가 해금되고, 레시피북 UI에 정상 표시됩니다.
- 레시피가 해금되지 않은 상태에서는 조리 시스템에서 정상적인 요리 결과를 받을 수 없으므로, 플레이 전 레시피북에서 필요한 레시피를 먼저 해금해야 합니다.
